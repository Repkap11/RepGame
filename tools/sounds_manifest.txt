#   source - file under sounds/ (untracked — not committed, see .gitignore).
#   type   - music | sfx. music plays in the ambient rotation; sfx are looked up
#            by base name (dig_stone_1/dig_stone_2 share the "dig_stone" pool
#            for random variants — the name minus the trailing _N is the base).
#   title  - display name for logging.
#   set    - music only: overworld | nether (default overworld) — the
#            dimension music set (DIM_MUSIC_*) the track rotates in.

# overworld (game/, game/water, game/creative) and nether (game/nether)
# tracks are listed; end, menu and record discs are excluded. To drop or add
